## 我改咗原計劃 3 個關鍵位

原計劃本身好紮實，但有 3 個位**會直接打倒「誠信」呢個教學目標**。已改，全部有原因：

### 1. 機器人唔可以提早洩漏答案 ⚠️ 最重要

原計劃寫「畫面 3：✅ 一樣就笑；❌ 唔一樣就『咦』」。
如果機器人喺學生自己回答之前就笑咗／「咦」咗，學生就知啱咗定錯咗 ——
**畫面 4 嘅「如實交代」就冇咗意義**，學生只會照抄答案。

改法：機器人由畫面 2 到畫面 3 **全程中性**（平嘴、無表情反應），
只做「提問」，唔做「判斷」。對錯反應**只喺學生自己答完之後**先出現。

連帶清走 3 個隱性洩漏位：放大檢視面板嘅 ✅/❓ 指示、已核對項目嘅**綠色**底色（學生會讀成「啱」）、逐項核對嘅即時對錯回饋。

### 2. 畫面 3 同畫面 4 唔可以問同一條問題

原計劃兩個畫面都問「一樣 / 唔一樣」。連續問兩次同一題，
學生第二次只會照抄第一次個答案，冇再思考。

改法分工：
- **畫面 3** ＝ 逐件自己核對（有喎 / 冇喎），教「一樣 / 唔一樣」呢個概念
- **畫面 4** ＝ 成張單一次過誠實交代（一樣 / 唔一樣）

兩個問題唔同層級：前者係技能，後者先係價值觀。

### 3. 答錯唔可以被 punish

原計劃「完成任務（包括誠實選擇）就有星星」方向啱，但要補一句：
**學生答「一樣」但實際唔一樣，都要讚**，因為佢肯答、肯面對。
系統講「多謝你話我知」，唔講「你講錯」。
誠信 ＝ 肯面對自己睇到嘅嘢，唔係 ＝ 一定答啱。

## 分層使用

| 層級 | 用乜 | 幾耐 |
|---|---|---|
| **A 入門**（主流入度） | 教材一 + **淨做第 1 單**，老師手把手 | 10 分鐘 |
| **B 常規** | 教材一，3 張單全做 | 20 分鐘 |
| **C 進階** | 教材二（數量配對，圓點代替數字） | 待開發 |

**A 級最重要**：中度智障學生嘅注意力大約喺第 1 單就開始跌。
唔好一開始就要求 3 張單做完。第 1 單跑完就已經係一個完整嘅學習歷程。

## 技術規格

| 項 | 值 |
|---|---|
| 技術 | 原生 HTML + CSS + JS，零依賴、零 CDN |
| 音效 | WebAudio 即時合成（冇外部音檔 = 離線可用） |
| 進度 | **刻意唔做持久化** — 課室會連續畀多個學生用，存咗就會跨學生污染 |
| 點擊範圍 | 最細 64×64px（貨架 66px、並排圖 74px、按鈕 180×84px 以上） |
| 對比度 | 正文 16.9:1，次要文字 8.6:1（WCAG AAA） |
| 動效 | 支援 `prefers-reduced-motion` |
| 操作 | 全 `<button>`，可鍵盤操作（老師用電腦示範時有用） |
| 適應 | 640px（分屏）到 1920px（投影）都唔會重疊或要 scroll |

老師可調參數喺 `prototype/index.html` 嘅 `CONFIG`：

```js
const CONFIG = {
  perItemCheck : true,  // false = 畫面 3 淨係並排睇，唔逐件問（更簡單）
  maxBasket    : 6,     // 籃容量上限
  sound        : true,  // 靜音班用
  speech       : true,  // 機械人粵語／中文 TTS；靜音班改 false
};
```

**貨架常駐清單**：入店後頂欄顯示而家呢張單 3 件圖，學生唔使靠記門口。  
**語音**：`say()` 同步 `speechSynthesis`（優先 zh-HK／粵語）。
