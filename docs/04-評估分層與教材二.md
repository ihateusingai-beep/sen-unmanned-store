# 04 · 評估、分層與教材二

## 一、我哋評咩、我哋唔評咩

呢個教材**唔計分**。咁要評咩？答案係一個位：

> **學生有冇「自己睇完」先答？**

兩個學生都答「唔一樣」，一個係睇完知道唔啱所以話出嚟，
另一個係亂撳 —— 誠信教育上完全唔同。
所以評估睇嘅係**誠實答覆同實際結果之間嘅關係**，唔係答啱定錯。

| | 誠實答覆 | 實際 | 讀法 |
|---|---|---|---|
| ✅ | 唔一樣 | 唔一樣 | **誠實** —— 有睇、有面對 |
| ✅ | 一樣 | 一樣 | **誠實** —— 有睇、有面對 |
| ⚠️ | 一樣 | 唔一樣 | **未核對就答** —— 要再教「數一次、對一次」 |
| ⚠️ | 唔一樣 | 一樣 | **未核對就答** —— 過度謙虛／唔肯定，要再教「睇清楚」 |

兩種 ⚠️ 都係教學位，唔係扣分位。

## 二、記錄表點讀

### 單張單睇

`paper/checklist.html` 第 7 頁，或者網頁版「老師」掣。

**關鍵欄：誠實答覆 vs 實際**

```
第 1 單  清單：蘋果、牛奶、餅乾
         攞到：蘋果、牛奶
         誠實答覆：唔一樣  實際：唔一樣   ✓ 誠實
```
呢個學生知道自己漏咗嘢，肯講出嚟 —— 呢個就係誠信。

```
第 2 單  清單：香蕉、朱古力、麵包
         攞到：蘋果、芝士、薯片
         誠實答覆：一樣    實際：唔一樣   ✗ 有落差
```
呢個學生**根本冇對過清單**。教學重點唔係「你揀錯」，
而係「取完嘢之後，要數一次、對一次先」。

### 全班睇

跑完 3 張單之後，填第 7 頁「全班統計」：

| 指標 | 意思 | 點解重要 |
|---|---|---|
| 誠實答覆 ≠ 實際 | 未自己核對就答 | 如果全班大部分都係咁，代表 A 級學生多，第 1 單唔夠 |
| 敢於答「唔一樣」 | 誠實交代 | 答「唔一樣」要勇氣（怕畀人話自己攞錯）。數字低 = 之前有壓力 |
| 三單都完成 | 專注力夠唔夠 | 撐唔到第 3 單好正常，唔係失敗 |
| 需要成人提示／接手 | 支援程度 | 決定下一屆要唔要減清單長度 |

## 四、教材二：數量配對版（設計已完成，待開發）

### 目標

已經穩陣掌握「一樣 / 唔一樣」之後，轉到「**一樣多**」。
用**圓點**代表數量，**唔用或極少用阿拉伯數字**。

### 四個畫面點改

| 畫面 | 教材一 | 教材二 |
|---|---|---|
| 1 門口 | 清單 3 件圖 | 清單 2-3 件圖，每件旁邊有 **N 個圓點** |
| 2 取貨 | 㩒一次 = 一件 | 㩒一次 = 一件。**用 `+1 / −1` 調整數量**（每次只調一件） |
| 3 核對 | 逐件問「有冇」 | **比較兩邊圓點數量**：「邊邊多啲？」 |
| 4 誠實確認 | 一樣 / 唔一樣 | 「你攞嘅嘢，同清單**一樣多**嗎？」 |

星星、小機器人、場景、流程**全部不變**。只改內容同核對問題。

### 圓點呈現

- 圓點直徑 ≥ 24px，間距 ≥ 8px（要睇得清「數幾多個」）
- **唔好排列成 5×2 十字咁** —— 中度智障學生容易當咗 1 個圖案
- 建議 1-5 個圓點直排或橫排，**唔超過 5**（一排一眼數得晒）
- 每加一個圓點出聲（`beep` 頻率逐個升高），學生聽聲都可以數

### 調整數量的互動

```
蘋果 ●●●          ← 清單要 3 個
籃度   ●●●  [+1] [−1]
```

- `+1` / `−1` 各一個大掣，每次只調一件
- 圓點即刻加/減，配合音效
- **系統唔會話「夠咗喇」** — 一樣係中性容量提示

### 分母：清單長度

教材二建議由 **2 件** 開始（清單 2 件 × 2 圓點），
第 3 單先升到 3 件。唔好一開始就 3 件 × 3 圓點。

### 開發時要注意（唔好重蹈教材一嘅覆轍）

1. **圓點數量唔可以即時回饋對錯** — 學生加到啱數唔好即刻出 ✅
   （同 `01` §A3 一樣，圓點一樣係中性色，唔係綠色）
2. **「多啲 / 少啲」一定要有視覺提示**，唔好淨靠讀字
   —— 可以用圓點大細變化，或者直接講「呢邊多」
3. **數量上限設一個合理值**（建議 5），
   避免學生撳到 20 個圓點，視覺上變成一坨
4. **逐項圓點核對要分段** —— 一次過比兩堆圓點，太多學生會懵。
   建議一次比一件

## 五、下一屆要先答嘅 3 個問題

1. **A 級學生比例係幾多？** 如果 > 50%，第 1 單可能要減到 2 件
2. **誠實答覆 ≠ 實際嘅比例？** 如果 > 70%，要加重「數一次對一次」嘅身體提示
3. **敢於答「唔一樣」嘅比例？** 如果低，檢討之前有冇不小心講咗「你攞錯」

呢 3 個數就係下一版要改乜嘅依據。
