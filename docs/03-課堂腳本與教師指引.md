# 03 · 課堂腳本與教師指引

---

## 一節課點跑（老師視角）

| 時間 | 老師做乜 | 學生做乜 |
|---|---|---|
| 0-2 分 | 講一次：今日係**無人商店**，攞咗嘢都要**付足錢**；呢度自己對清楚，再老實講 | 聽 |
| 2-4 分 | 按「開始入店」→ 揀第 1 單 | 揀單 |
| 4-8 分 | **唔好講嘢**。學生慢慢㩒貨 | 取貨 |
| 8-12 分 | 「我睇清楚晒啦」之後，學生逐件答有／冇 | 逐件核對 |
| 12-15 分 | 讀出誠實確認問題 | 揀 **一樣 / 唔一樣** |
| 15-17 分 | 睇結果畫面，**唔好評論啱唔啱** | 聽 |
| 17-20 分 | 開「老師記錄」撳 `T`，填第 1 單嗰行 | 等下一個同學 |

**跑完第 1 單就停，問學生攰唔攰。**
想繼續先跑第 2、3 單。

## 逐句引導語

### 開場（唯一一次講規則）

> 「今日係**無人商店**。攞咗嘢都要**付足錢**。
> 呢度你幫小機器人對清單：**自己睇清楚**，再**老實講**有冇攞錯。
> 答錯都冇問題，最緊要係老實——好似付足錢咁。」

最後一句一定要講。冇講，學生會以為要答啱先有星星。

### 畫面 2 取貨

| 學生情況 | 你講 |
|---|---|
| 開始郁唔到 | 「㩒你鍾意嗰樣㗎。」 |
| 同一樣㩒好多次 | 「㩒咗喇，放入籃度㗎。」 |
| 亂㩒 | 「慢慢嚟，我哋一齊睇。」 |
| 完全唔郁 | 唔好代㩒。手指指住貨架：「喺度㗎。」等 10 秒。 |

**唔好用**：「你應該㩒呢樣」— 一講咗就冇咗自己判斷。

### 畫面 3 逐項核對

學生㩒一件嘢之後：

> 「睇下左邊清單有冇呢一樣。」

- 學生答「有」／「冇」之後 → **唔好話啱定錯**
- 答完直接出下一件
- 全部睇完 → 撳「我睇清楚晒啦」

### 畫面 4 誠實確認（＝付足錢 · 最重要 30 秒）

讀出呢句，然後**收聲，唔好補充**：

> 「無人店冇人睇住都要付足。咁你攞嘅嘢，同清單**一樣**嗎？」

然後等。**等耐啲**。中度智障學生需要 5-10 秒先出聲。

| 學生 | 你講 |
|---|---|
| 答「唔一樣」 | 「多謝你老實講！付足錢就係咁。」（跟系統講漏／多） |
| 答「一樣」，真係一樣 | 「自己對清楚再講，就係付足錢嘅誠信。」 |
| 答「一樣」，唔一樣 | 「**多謝你講。**下次對清楚先。」（唔好跟「你攞錯咗」） |

### 收尾

> 「你今日自己對清楚，好似無人店付足錢咁老實。」

唔好講「你今日表現好好」—— 太籠統，學生唔知係邊件事做得好。

## 🚫 唔好做嘅事

| 唔好 | 點解 |
|---|---|
| 「你攞錯咗㗎啦」 | 一講咗，畫面 4 就冇咗意義 |
| 「應該係呢樣㗎」 | 直接代替咗學生自己核對 |
| 幫學生撳掣 | 冇咗自己決定 |
| 「大家都攞咗星星喎」 | 呢個活動冇人輸，但提「大家都」會製造比較 |
| 「你今日有 3 顆星，好叻」 | 如果佢 3 次都亂撳，一樣有 3 顆。星星獎「肯答」，唔係獎「答啱」 |
| 倒數計時 / 限時 | 原計劃已定：無壓力 |

## 學生卡住點算

按情況由上到下試：

1. **等 10 秒** — 中度智障學生反應慢係正常，唔好急
2. **重複問題，簡化措辭** — 「睇下有冇？」代替「呢個嘢清單上面有冇」
3. **手勢輔助** — 指向清單嗰欄（**唔好指向答案**）
4. **句子式代替選擇題** — 「攞咗 3 樣，清單要 3 樣，啱唔啱？」
5. **降級** — 撳「我攞完啦」之前先幫佢「數一次有幾多樣」

第 5 步仍然唔得，就記低低咗一格，轉下一個同學。
**卡住唔係失敗**，係資料。

## 多人 / 分組

| 方式 | 點做 |
|---|---|
| 一人一機 | 最直接。老師用「老師記錄」逐個記 |
| 一部投影，全班一齊答 | 可行，但老師要守住唔講答案嘅紅線 |
| 小組 + 紙本 | 用 `paper/checklist.html` 第 4-6 頁圖卡，每組一套 6 張 |

**小組玩法**：每人輪流做「店員」（讀問題、記答案），其餘做「顧客」（擺圖卡、答）。
逼每個學生都要做一次誠實表達。

- [ ] 列印 `paper/checklist.html` 一份試睇圖卡夠唔夠大、黑白影印仲睇唔睇得清
- [ ] 「老師記錄」撣一聲試下（鍵盤 `T` 都得）
- [ ] 關閉其他分頁，避免學生撳錯

## 環境注意

| 情況 | 處理 |
|---|---|
| 冇網 | **冇問題**，兩個檔都係零依賴單檔 |
| 學生中途亂撳重載 | 進度會清零（刻意設計，見 `01` §C1）。用 F5 鎖定頁面可減少誤觸 |
| 電腦冇喇叭 | 冇聲都跑得齊，音效唔影響流程 |
| 學生想即刻再開 | 證狀畫面有「🔄 重新開始」掣 |
