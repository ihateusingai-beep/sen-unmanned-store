## 三張清單

| | 正貨（清單上，3 件） | 干擾（架上唔喺清單，3 件） |
|---|---|---|
| **第 1 單** | 🍎 蘋果　🥛 牛奶　🍪 餅乾 | 🍌 香蕉　🍞 麵包　🥚 雞蛋 |
| **第 2 單** | 🍌 香蕉　🍫 朱古力　🍞 麵包 | 🍎 蘋果　🧀 芝士　🍟 薯片 |
| **第 3 單** | 🍇 葡萄　🌽 粟米　🧀 芝士 | 🍌 香蕉　🧃 果汁盒　🍐 梨 |

### 三條排清單嘅規則

**1. 每張單 3 正 + 3 干擾 = 6 件 = 貨架 3×2 兩行滿格**
唔會出現孤行，掃視負擔最低。

**2. 同一個畫面唔可以出現外型相近嘅一對**

最易出事係飲品：🧃 紙盒飲品 vs 🥤 杯飲品，兩個都係「飲品」，
對中度智障學生係同一個 concept。**所以三張單都冇用 🥤，
亦都冇同一張單同時出現 🧃 同 🥛。**

第 3 單原本用「葡萄 / 汽水 / 糖果」，因為 🧃 同 🥤 會撞，
改成「葡萄 / 粟米 / 芝士」—— 三樣都係完全唔同形狀同顏色。

**3. 每張單至少一類飲品 / 一類零食，類別唔會全部一樣**

第 1 單 水果+飲品+零食、第 2 單 水果+零食+主食、第 3 單 水果+菜+奶製品
—— 令「清單有咩」唔可以用「全部都係水果」呢個錯覺去猜。

## 想換插圖（emoji → SVG / 實物相）

**只需要改 `ITEMS` 一個 map。** 兩個檔案嘅資料都係獨立一份，
所以要兩邊一齊改（見下方改動清單）。

### 步驟

**1. 準備 15 個 SVG 或 PNG（透明底、正方形、同一畫風）**

建議 512×512、單色描邊 + 平塗色、最粗唔細過 viewBox 邊界 5%。
純線條（無填色）對某啲學生更易分辨，但要確認投影機夠對比。

**2. 改 `ITEMS`**

```js
// 改前
const ITEMS = {
  apple: {emo:"🍎", name:"蘋果"},
  ...
};

// 改後
const ITEMS = {
  apple: {img:"assets/apple.svg", name:"蘋果"},
  ...
};
```

**3. 改模板入面嘅 `ITEMS[id].emo` → `ITEMS[id].img`**

| 位置 | 現行寫法 | 改成 |
|---|---|---|
| 門口清單卡 | `<span class="dot">${ITEMS[id].emo}</span>` | `<img class="dot" src="${ITEMS[id].img}" alt="">` |
| 貨架 tile | `<span class="emo">${ITEMS[id].emo}</span>` | `<img class="emo" src="${ITEMS[id].img}" alt="">` |
| 購物籃 | `s.textContent = ITEMS[id].emo` | `s.innerHTML = '<img src="'+ITEMS[id].img+'" alt="">'` |
| 核對枱清單 | `d.textContent = ITEMS[id].emo` | `d.innerHTML = '<img src="'+ITEMS[id].img+'" alt="">'` |
| 核對枱籃 | `b.textContent = ITEMS[id].emo` | 同上 |
| 放大面板 | `$("#zoomEmo").textContent = ITEMS[id].emo` | `$("#zoomEmo").innerHTML = '<img ...>'` |

**4. 加 CSS**（`emoji` 類名大小寫唔同，要兩套都加）

```css
img.emo, img.dot{ width:1em; height:1em; object-fit:contain; }
.tile img.emo{ font-size:0; width:clamp(3rem,7vw,4.4rem); height:clamp(3rem,7vw,4.4rem); }
.mini img    { width:74%; height:74%; object-fit:contain; }
#basket img   { width:1.9rem; height:1.9rem; }
#zoom img     { width:clamp(2.6rem,8vw,4.6rem); height:clamp(2.6rem,8vw,4.6rem); }
```

**5. `paper/checklist.html` 獨立改一次**（同一個 `ITEMS` map，但模板係另一份）
